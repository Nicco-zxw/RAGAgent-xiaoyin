# 04 AI辅助、个人贡献与验证

## AI使用范围

主要实现由Codex辅助完成，包括方案细化、Python代码、合成制度、测试与证据导出脚本、本地命令执行、接口诊断、文档整理和结果分析。问答及语义审查使用真实deepseek-flash；离线Mock只用于流程模拟，不作为真实模型效果证明。

## 提交者确认的个人贡献

以下内容由提交者在对话中确认，不将AI完成的工作改记为个人独立编码：

- 参与优化提示词；具体逐行修改或版本差异未另行记录，不声称独立编写全部提示词。
- 负责需求与验收标准确认，推动按题目覆盖核心链路与实际证据。
- 负责真实模型配置，提供本地.env接入并协调服务恢复。
- 完成最终结果复核，核对答案引用、冲突处理和执行记录。

代码、测试脚本与文档主要由AI生成和修改。AI执行的测试与提交者个人复核分别披露，不将AI测试记为个人独立运行。

## 验证与记录边界

[真实证据入口](../examples/README.md)与[评估文档](03-evaluation.md)提供AI执行的实际结果；个人复核依据提交者自述确认，不声称存在独立审核证书。具体逐例复核批注、独立运行命令、个人有效投入及完整开发用时未另行提供，不虚构。历史全过程未计时，保留计时缺口。

本文件区分已确认范围与未单独确认的任务。历史错误、接口失败、审查关闭未达标结果未删除。
